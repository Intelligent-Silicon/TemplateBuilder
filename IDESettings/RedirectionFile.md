# Redirection File

The Redirection file contains the folder paths the IDE uses to find or place different files. 

This lets us create templates in different sub folders from an ```.app``` file, and provided the path to the subfolder is added to the Redirection File, the Template Registry will find and load.

| Clarion Version | IDE Menu Options | File Location |
| -- | -- | -- |
| C6 | Setup > Edit Redirection File | C:\Clarion6\BIN\C60EE.RED |
| C7+ | Tools > Edit base Redirection File | C:\Clarion11\bin\Clarion110.red |


### File Masks

Two DOS [WildCards](https://en.wikipedia.org/wiki/Wildcard_character) are used in the Redirection file in all versions of Clarion. 

```*``` match any character any number of times to the right of where its placed, until it encounters another character in the file mask.

```?``` match any character once only where it is placed.

MS Windows does not use Case Sensitivity by default unlike *nix operating systems, but with the introduction of Windows Subsystem Linux (WSL), mainstream [Case Sensitivity](https://learn.microsoft.com/en-us/windows/wsl/case-sensitivity) was introduced to accommodate *nix running on Windows.

There is however a little known Reg Setting which also controls [Windows Kernel Case Sensitivity](https://learn.microsoft.com/en-us/troubleshoot/sql/database-engine/install/windows/sql-server-not-supported-in-windows-os-where-case-sensitivity-enabled) that has affected programs including MS SQL Server, because MS SQL Server needs Windows to be Case Insensitive regardless of WSL being installed or not, and this applies to earlier versions of Windows which may go all the way back to the start of NT and Windows 3.1.

Case Insensitive - Default setting if omitted from the Windows Registry.
```
[HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Session Manager\kernel]
"obcaseinsensitive"=dword:00000001
```

Case Sensitive
```
[HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Session Manager\kernel]
"obcaseinsensitive"=dword:00000000
```


Example File masks. 

| File Mask | Notes | Examples |
| -- | -- | -- | 
| *.[File Extension] | Matches any filename with the same [File Extension] | *.txt, *.md *.clw, *.inc |
| *.tp? | Matches any filename with a file extension beginning with .tp and ending with any single character | *.tpr, *.tpl, *.tpw |
| tb*.tp? | Matches any filename beginning with TB (not kernel case sensitive) with a file extension beginning with .tp and ending with any single character | TBProcedure.tpl, TBFramework.tpl, TBv2Button.tpw |
| *.FileList.xml | Matches any filename ending with .FileList.XML | [Some App Filename].FileList.xml |



### Redirection Macros

You will encounter Redirection Macros (labels encompassed with ```%``` eg ```%TEMP%```), in the folder locations of file masks.

There are built-in redirection macros, but you can add your own to suit your programming environment. 


| Version | Built-in | Folder Location | Redirection File |
| -- | -- | -- | -- |
| C6 | %ROOT% | [Clarion installation Folder] eg C:\Clarion6 | C:\Clarion6\BIN\C60[PE\|EE].red |
| C6 | %BIN% | [Clarion installation Folder] eg C:\Clarion6\bin | C:\Clarion6\BIN\C60[PE\|EE].red |
| C7+ | %libpath% | Project .lib file folder. For copying Clarion.NET files. Mimics .NET Core assembly behaviour | C:\Clarion11\bin\Clarion110.red |
| C7+ | %configuration% | For copying Clarion.NET files. Mimics Clarion.NET behaviour | C:\Clarion11\bin\Clarion110.red |

### C6 Redirection Macro

In C6 to add new redirection macros, simply add them to the Clarion IDE configuration ini setting file ```Clarion Installation Folder\Bin\C60[PE|EE].ini```.

The ```[Redirection Macros]``` section is missing by default so you need to add this to the ini file if you want to use it, standard [ini file](https://en.wikipedia.org/wiki/INI_file#Format) rules apply.

```
[Redirection Macros]
TEMP=c:TEMP
```

### C7 Redirection Macro

In C7 or later, you can add the Redirection Macros using the IDE interface found at Tools > Options.

In the Options window lefthand navigation pane select Clarion > Clarion for Windows > Versions 

Then select the Redirection File tab, where you can add a new Macro Symbol and a value.

The file storing additional Redirection Macros can be found in the ```ClarionProperties.xml``` file which largely replaces the various C6 ini files and others.
```
C:\Users\[UserName]\AppData\Roaming\Softvelocity\Clarion\[Major Version].0\ClarionProperties.xml
```

The ```ClarionProperties.xml``` section which stores additional Redirection Macros.
```
<Properties name="Macros">
	<root value="C:\Clarion11"/>
	<reddir value="C:\Clarion11\bin"/>
	<[Macro Symbol] value="[value]" />
</Properties>
```				

The root value can also found in the Reg Setting below but it does not update the ```ClarionProperties.xml``` file.
```
[HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\SoftVelocity\Clarion11]
"root"="C:\\Clarion11"
```

Structure of the wider ```ClarionProperties.xml``` file.
```
<ClarionProperties>
	<Properties name="Clarion.Versions">
		<Properties name="Clarion [Major Version].0.[xxxxx]">
			<path value="C:\Clarion11\bin"/>
			<IsWindowsVersion value="True"/>
			<IsClarion62 value="False"/>
			<Properties name="RedirectionFile">
				<Name value="Clarion110.red"/>
				<SupportsInclude value="True"/>
				<Properties name="Macros">
					<root value="C:\Clarion11"/>
					<reddir value="C:\Clarion11\bin"/>
					<[Macro Symbol] value="[value]" />
				</Properties>
			</Properties>
			<libsrc value="C:\Clarion11\Accessory\libsrc\win;C:\Clarion11\libsrc\win"/>
			<Properties name="Compilers">
				<clw value="Claclw.dll"/>
				<cpp value="Clacpp.dll"/>
				<mod value="Clamod.dll"/>
				<asm value="Claasm.dll"/>
				<lpe value="Clalpe.dll"/>
			</Properties>
			<CWVersion value="11000"/>
			<WideAppgenDialogs value="True"/>
			<ini value=""/>
			<DdeTimeOut value="0"/>
		</Properties>
	</Properties>	
</ClarionProperties>	
```




### File Paths

The Redirection File uses the [DOS 8.3 filename syntax](https://learn.microsoft.com/en-us/windows/win32/fileio/naming-a-file?source=recommendations#short-vs-long-names) by default, but does allow long folder (& file) names provided the folder is encompassed with double quotes.

To be aware of all the requirements for how to specify folder and file names, in particular using long folder and file names, visit https://learn.microsoft.com/en-us/windows/win32/fileio/naming-a-file


| Valid | Path | Notes |
| -- | -- | -- |
| Yes | C:\Clarion6\Bin | DOS 8.3 filename syntax |
| Yes | "C:\C6 Work" | The double quotes tells Windows this is a long folder name |
| Yes | "C:\MyC6WorkFolder" | The "MyC6WorkFolder" folder is treated as a long folder name | 
| No | C:\C6 Work | The space character between C6 and Work is not valid in DOS 8.3 filename syntax | 
| No | C:\MyC6WorkFolder | The MyC6WorkFolder folder is too long for the DOS 8.3 filename syntax | 



### Redirection File formats

The Redirection file can have multiple paths attached to a single File Mask entry ```*.tp?``` using a semi colon ```;``` as a divider. 

I have not found any limit to the number of paths which can be appended, but there must be one.

```
[Common]
-- C6 Default Entry
*.tp? = %ROOT%\template; %ROOT%\3rdparty\template

[Common]
-- C11 Default Entry
*.tp? = %ROOT%\template\win; %ROOT%\accessory\template\win
```


The same File Mask can be used on multiple lines, with each pointing to a different folder location.

```
[Common]
-- C6 Entries
*.tp? = %ROOT%\template; %ROOT%\3rdparty\template
*.tp? = "C:\C6 Work\TB1"; "C:\C6 Work\TB2.1"; "C:\C6 Work\TB3"; "C:\C6 Work\TB4"; "C:\C6 Work\TB5"; "C:\C6 Work\TB7"

[Common]
-- C11 Default Entry
*.tp? = %ROOT%\template\win; %ROOT%\accessory\template\win
*.tp? = %ROOT%\accessory\template\dotnet
*.tp? = %ROOT%\accessory\template\python
*.tp? = %ROOT%\accessory\template\c
*.tp? = %ROOT%\accessory\template\cplusplus
*.tp? = %ROOT%\accessory\template\perl
*.tp? = %ROOT%\accessory\template\java
*.tp? = %ROOT%\accessory\template\html
*.tp? = %ROOT%\accessory\template\javascript
*.tp? = %ROOT%\accessory\template\cobol
*.tp? = %ROOT%\accessory\template\pascal
*.tp? = "C:\C6 Work\TB1"; "C:\C6 Work\TB2.1"; "C:\C6 Work\TB3"; "C:\C6 Work\TB4"; "C:\C6 Work\TB5"; "C:\C6 Work\TB7"
*.tp? = "C:\C11 Work\TBFramework"; "C:\C11 Work\TBProcedures"; "C:\C11 Work\TBLanguage"
```

In C7 there is a new filemask entry for the Template Registry. 

```
*.trf = %ROOT%\template\win
```

### Redirection File Loading Order

Both the C6 and C7+ IDE's will look for a Redirection file in the following order, noting with C7+ and onwards the template registry is loaded from the Redirection file.

### C6 Loading Order

| Order | Filename | Location | Example |
| -- | -- | -- | -- |
| 1 | [.app filename].red | Application (.app) file folder | C:\C6 Work\MyTestApp\testapp.red |
| 2 | C60[PE\|EE].red | Application (.app) file folder | C:\C6 Work\MyTestApp\C60[PE\|EE].red |
| 3 | C60[PE\|EE].red | IDE folder | C:\Clarion6\bin\C60[PE\|EE].red |


```
C50[PE|EE].red
C55[PE|EE].red
C60[PE|EE].red
```


### C7+ Loading Order

The naming of Redirection Files changed slightly from C7 onwards, changing from ```C[two digit version number].red``` to ```Clarion[Clarion Major Version]0.red```.

```
Clarion70.red
Clarion80.red
Clarion90.red
Clarion100.red
Clarion110.red
Clarion120.red
```

| Order | Filename | Location | Example |
| -- | -- | -- | -- |
| 1 | [.app filename].red | Application (.app) file folder | C:\C6 Work\MyTestApp\testapp.red |
| 2 | Clarion[Clarion Major Version]0.red | Application (.app) file folder | C:\C6 Work\MyTestApp\Clarion110.red |
| 3 | Clarion[Clarion Major Version]0.red | IDE folder | C:\Clarion11\bin\Clarion110.red |




### Redirection File Sections

The redirection file can be separated into sections like an ini file, where some sections are dependant on the Project System settings. 

The options for 32bit in C6 are left overs from earlier versions of Clarion when the option to compile a 16bit or 32bit EXE/DLL existed.

Today C6 and later versions of Clarion, all compile 32bit EXE/DLL's for Windows.

However TemplateBuilder can operate largely outside of the Project Settings in order to produce templates which can call external compilers and pass settings to these compilers to build programs for any number of OS's and bitness.

| Section Name | Project System Switch | C6 | C7+ | Notes |
| -- | -- | -- | -- | -- |
| Debug | Debug Mode EXE | No | Yes | Either Debug or Release |
| Release | Build Release EXE | No | Yes | Either Debug or Release |
| 32 | Target EXE = 32-bit | Yes | No | |
| Debug32 | Debug Mode EXE & Target 32-bit | Yes | No | Either Debug32 or Release32 |
| Release32 | Build Release EXE & Target 32-bit | Yes | No | Either Debug32 or Release32 |
| Common | *** Not a Project System Switch *** |  Yes | Yes | Always in use |
