# Clarion TemplateBuilder

Status: Active Development.

Compatible Versions: C6 or later.

### General

Clarion TemplateBuilder is a clarion template that runs in the AppGen generating templates and template code.

For a more detailed info of a Clarion Template visit https://clarion.help/doku.php?id=what_templates_are.htm

TemplateBuilder speeds up the process of a writing a template, no matter how simple or complicated it is, better than any Ai LLM in production! 

Decades of programming experience, and hardware knowledge can be rolled into a template, to avoid buggy code, hallucinations and beginners errors.

TemplateBuilder can build templates to create frameworks and generate code in any of the 8000+ programming languages that exists today.

The speed and simplicity for generating and compiling a MS Windows app using the Clarion programming language, is available for all programming languages.

TemplateBuilder can call external Windows DLL's to interact with other development tools, including external internet services, internal services, Cloud based and local Ai LLM's, and any number of housekeeping tools to aid the development of coding projects.
